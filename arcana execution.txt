STEP 3 — THE EIGHT INVARIANTS (PRD §11A.3) — NEVER VIOLATED
═══════════════════════════════════════════════════════════════════════

  1. Grounding before generation         — no claim without retrieval
  2. UI is data, never code              — agents emit typed blocks
  3. Only the UI Agent picks components  — other agents emit payloads
  4. Agents contribute to shared state   — never overwrite arbitrarily
  5. Uniform composability               — only via route_to_agent
  6. Always terminate at UI Agent        — never raw text to client
  7. Storage behind abstractions         — never import a concrete store
  8. No secret literals                  — everything via Settings

The .claude/hooks/ will block violations of #7 and #8 automatically.
The code-reviewer subagent will check the others. Run it on every diff
before you call something done.
